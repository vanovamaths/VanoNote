Built around real handwriting.

The application runs locally, keeps the note database on your Mac, and supports a pen-first workflow for lectures, mathematical work and document annotation.

✎

Pen & XP-Pen

Pressure-aware strokes, smoothing, calligraphy, highlighter, eraser, lasso and configurable pen behavior.

▤

PDF workspace

Import PDFs and images, render pages at high resolution and annotate directly with the same handwriting tools.

◉

Classroom mode

Turn a note into a teaching whiteboard, move between pages and share a trusted local-network view with students.

◫

Study tools

Typed notes, LaTeX snippets, local summaries, flashcards and quizzes live beside handwritten pages.

⌘

Native macOS shell

Run VanoNote inside its own desktop window through WKWebView, with a dedicated app icon and Retina-aware canvas.

⌂

Local-first data

Notes, audio, attachments and backups remain in the local VanoNote folder instead of being uploaded by default.

Install on macOS.

Clone the public repository, install dependencies and create the native VanoNote application bundle.

git clone https://github.com/vanovamaths/VanoNote.git
cd VanoNote
chmod +x *.command
./install_dependencies.command
./install_vanonote_retina_app.command

VanoNote is local-first. Do not publish your local data/vanonote.db, attachments, recordings or backups.
