# Security

VanoNote is designed as a local-first application.

## Network use

The classroom-sharing server can listen on the local network. Treat it as a trusted-network feature and do not expose port `8766` directly to the public internet. Use an authenticated VPN or reverse proxy for remote access.

## Reporting a vulnerability

Please open a GitHub issue for non-sensitive security improvements. For vulnerabilities that could expose user data, contact the repository owner privately rather than posting exploit details publicly.
